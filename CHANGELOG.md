# Changelog

## 0.1.0 — Initial release

- Eight frequently used applications in a compact, themed grid.
- Local usage learning, a cooldown, and gradually decaying scores.
- Search all visible installed applications and focus existing windows.
- Keyboard and mouse navigation, including numbered slot shortcuts.
- Configurable starter apps, exclusions, class aliases, and learning controls.
- English/Spanish strings with native 4.5 language switching and a 4.0.x fallback.
- Isolated QML tests against 4.0.6 and 4.5 shell components, model tests, and CI.
- Owner-only history storage and pinned, read-only CI dependencies.

Runtime verification covers Omarchy 4.5.0rc1-1. The complete 4.0.6 desktop remains
an additional release-validation target, as detailed in docs/COMPATIBILITY.md.
