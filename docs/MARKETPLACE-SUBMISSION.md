### Maintainer notes

Quick Apps shows eight frequently used apps in a compact searchable grid. It
learns from desktop app switches, opens or focuses existing windows, and stores
aggregate usage locally. No telemetry or network calls.

Plugin ID: `andean-bridge.quick-apps`. MIT license. Uses the existing Omarchy
Quickshell/Hyprland runtime; no additional runtime dependencies, sudo, installer
hook, or service. It does not change keybindings automatically. README includes
installation, configuration, update, disable/removal, and data deletion.

Tested on Omarchy 4.5.0rc1-1, with isolated integration checks against upstream
4.0.6 UI components. Full 4.0.6 desktop validation is not yet complete; this is
documented rather than claimed as fully verified. The preview is a cropped
capture of the plugin's own UI.
